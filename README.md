# Masking Effects on XAI Techniques

A bachelor thesis project investigating how different data anonymization techniques affect the performance and reliability of Explainable AI (XAI) methods.

## Overview

This project explores the impact of privacy-preserving data masking techniques on XAI explanations.  Specifically, it examines how four anonymization models: $k$-anonymity, $\ell$-diversity, $t$-closeness, and $(\alpha, k)$-anonymity, affect the explanations generated by LIME and SHAP, two popular XAI methods.


## Evaluation Metrics

The project includes notebooks analyzing various aspects of XAI explanation quality:

- **Stability**:  Consistency of explanations across similar inputs
- **Rank Correlation**: Agreement between feature importance rankings
- **Hierarchy Effect**: Impact of hierarchical data masking
- **Utility vs Generalization**: Trade-offs between data utility and model generalization

## Getting Started
The project uses two branches actively. The `main` branch (this one) and the `anonymization` branch. The `anonymization` branch concerns itself with preprocessing and generating anonymized variants of datasets, while the `main` branch generates explanations and analyze the results. 

All the code can be run locally, but due to the slow computation of LIME and SHAP values, DTU's HPC cluster has been used to do most computations. All code related to the HPC cluster is located under the `hpc` folder, and uses this repo as it's only dependency. If you do not have access to the DTU HPC cluster, the code in the `hpc` folder should be able to run on any cluster that utilizes **IBM Spectrum LSF**.

The [LIME Repository](https://github.com/marcotcr/lime) has been [forked](https://github.com/Zak9O/lime) because it is no longer maintained, and the repo has been refactored slightly by the authors of this repo. 

### Required software

- Python 3.12 or higher
- [uv](https://github.com/astral-sh/uv) package manager

## Running Experiments

Navigate to the `notebooks/` directory and launch JupyterLab:

```bash
uv run jupyter lab
```

Each notebook focuses on a specific aspect of the research: 

- **Hierarchy Effect**: Analyze how hierarchical masking affects explanations
- **LIME/SHAP Explanation**: Generate and compare explanations for specific instances
- **Rank Correlation**: Measure agreement between feature rankings
- **Stability**: Evaluate explanation consistency
- **Topology**: Examine structural properties of explanation spaces
- **Utility vs Generalization**:  Assess trade-offs in model performance

## Research Context

This work is part of a bachelor thesis investigating the critical intersection of privacy protection and explainability in machine learning. As AI systems are increasingly deployed in sensitive domains (healthcare, finance, etc.), understanding how privacy-preserving techniques affect explainability is essential for building trustworthy AI systems.
